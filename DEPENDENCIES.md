# Dependencies

Only these libraries are allowed. Adding one requires approval and an entry here.

Runtime: Node 22 or newer (pinned in `.nvmrc`, declared in `engines` in each package.json, so npm warns on older versions) and Go 1.22 or newer.

## Go (server/)
| Package | Why | Rules |
|---|---|---|
| standard library (net/http, database/sql, log/slog, net/smtp, embed, os/exec) | ServeMux patterns since Go 1.22 cover our routing; fewer deps to explain | No web frameworks |
| github.com/robfig/cron/v3 | Mature cron parser and scheduler with timezone support | Standard 5-field cron plus descriptors like @daily |
| modernc.org/sqlite | Pure-Go SQLite: no CGO, simple Docker builds (ADR-0003) | One connection, WAL mode, busy timeout |

Not allowed: gin, echo, fiber, gorm, sqlx, viper, any ORM.

## Agents (agents/)
| Package | Why | Rules |
|---|---|---|
| @playwright/test | Test runner and browser automation | Tests import from tests/_support/fixtures.ts |
| zod | Schemas for tool args, LLM outputs and CLI input; converts to JSON Schema for tool declarations | Every external input is parsed with zod |
| @google/genai | Gemini SDK, default provider (ADR-0005) | Only used inside src/llm/gemini.ts |
| @anthropic-ai/sdk | Anthropic SDK, alternative provider | Only used inside src/llm/anthropic.ts |
| diff | Create unified diffs for heal proposals | |
| tsx | Run TypeScript directly | |
| vitest | Unit tests | |
| typescript, @types/node | Types | strict mode |

Not allowed: langchain, langgraph, crewai, llamaindex, any agent framework, axios.
